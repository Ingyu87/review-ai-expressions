# AI 표현 검토

한국어 문서·보고서·계획서·슬라이드·발표 대본의 상투적인 표현과 어색한 문장을 문맥에 맞게 검토하고 수정하는 Codex 스킬입니다.

원문의 뜻, 수치, 조건, 전문 용어와 서식을 보존합니다. 이미 자연스러운 문장은 유지하며, 단어를 일괄 치환하지 않습니다. 비유나 추상 표현도 문맥에서 이해·전환·강조에 도움이 되면 유지하고, 의미를 흐리거나 불필요한 반복을 만들 때만 고칩니다. 문서와 슬라이드에 섞인 제작자용 작업 과정도 독자에게 필요한지 판단해 삭제하거나 독자용 문장으로 고치고, 발표자에게만 필요한 내용은 노트로 분리합니다. 필요한 표현과 요소는 사용 이유를 확인한 뒤 유지합니다. AI 작성 여부를 판별하거나 AI 탐지 회피를 보장하는 도구는 아닙니다.

## 구성

- `SKILL.md`: 적용 범위, 판단 기준, 매체별 수정 지침
- `agents/openai.yaml`: 스킬 표시 이름과 기본 프롬프트
- `.codex/`: 저장소 관리와 다른 컴퓨터에서 작업을 이어가기 위한 정보

## 설치

이 저장소의 `SKILL.md`와 `agents` 폴더를 개인 Codex 스킬 폴더 아래 `review-ai-expressions` 폴더에 복사합니다. 기존에 설치되어 있다면 필요한 변경 사항을 확인한 후 업데이트합니다.

### Claude Code

PowerShell에서 다음 설치 스크립트를 실행하면 개인 스킬과 `/ai표현` 명령이 함께 설치됩니다.

```powershell
.\scripts\install-claude-code.ps1
```

설치 후 Claude Code에서 다음처럼 호출합니다.

> /ai표현 검토할 파일이나 요청

설치 스크립트는 `SKILL.md`를 `~/.claude/skills/review-ai-expressions/`에, 한글 명령 별칭을 `~/.claude/commands/ai표현.md`에 복사합니다. 다른 PC에서는 저장소를 내려받거나 업데이트한 뒤 같은 스크립트를 다시 실행합니다.

## 사용 예시

검토 의견만 받을 때:

> $review-ai-expressions 이 문서에서 어색한 표현을 찾아 수정 제안과 이유를 알려줘. 원본은 수정하지 마.

수정된 자료를 만들 때:

> $review-ai-expressions 이 자료의 AI식 표현을 검토하고, 의미와 원본 양식을 유지하면서 문맥에 맞게 수정해줘.
